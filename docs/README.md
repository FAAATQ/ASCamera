# 文档维护约定

- 从 [INDEX](INDEX.md) 定位主题；短文档按职责拆分，避免综合巨型设计文档。
- `gameplay/` 记录交互规则；`gameplay/content/` 记录控件标签、参数与内容数据。
- `technical/` 记录实现与验证；`architecture/` 记录依赖、所有权和生命周期。
- 事实以当前源码为准；历史决策保留在 PROCESS，明确标记被替代行为。
- CURRENT 只写当前状态；TODO 只写未完成事项；LOG 链接阶段记录。
- 用户确认决策、源码事实、建议、待验证事项分开描述。
- 测试记录须写明对应版本和实际执行结果；历史通过不等于当前通过。
- 本轮只建立文档基线，不代表功能验收或新增开发授权。
